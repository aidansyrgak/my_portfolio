Hospital Application

Hospital Navigation and Service Request Application

Software engineering project in collaboration with Brigham & Women’s Hospital. This project had ten-person student teams working in a competition to apply Agile development methodologies and software design patterns in Java to prototype a hospital operations application. The application focused on map-based navigation and service requests. It was then presented to the hospital dev team for potential features, UI concepts, and design directions for future development.

Embedded Security

Secure Voice-Controlled Car

A voice-controlled car door system that responds to spoken commands while defending against microphone-based attacks including laser injection, ultrasound, and electromagnetic interference. Built on Raspberry Pi with two USB microphones, servo motors, and light sensors, the system implements multi-layered security defenses including dual-mic consistency checks, laser detection, ultrasound analysis, and OTP verification. Developed collaboratively with two other graduate students, the system successfully defended against other teams' attacks during a live tournament.

Features:

  • Voice command recognition using Google's Speech-to-Text API.
  • DTMF tone detection for precise partial door opening control.
  • Dual-microphone energy consistency checks to detect single-channel injection attacks.
  • BH1750 light sensors for real-time laser attack detection through lux monitoring.
  • FFT-based ultrasound defense analyzing 15-22 kHz spectrum to block inaudible signal injection.

Cache Simulator

Cache Simulator

This tool explores how CPU cache parameters can be inferred using only memory access behavior, without inspecting internal cache state. I built a DineroIV-style cache simulator and a trace-driven analyzer that generates targeted memory reference streams and interprets aggregate hit/miss results to deduce cache info (block size, capacity, associativity, replacement policy). The analyzer uses black-box testing to infer cache behavior from simulator output, mirroring real-world trace-based cache analysis.

Features:

  • Configurable simulator that models CPU cache behavior across multiple architectures.
  • Supports direct-mapped, 2-way set associative, 4-way set associative, and column-associative configurations.
  • Column-assoicative cache implemented as described by Agarwal and Pudar in this paper.
  • Cache associativity inference using controlled set conflicts.
  • Replacement policy differentiation through ordered access patterns.

Indirect Branch Predictors

Designing, Simulating, and Evaluating Indirect Branch Predictors

Developed Python-based simulators for multiple indirect branch predictor architectures and evaluated their performance across different workloads. Using a custom Intel Pin tracing tool, captured indirect branch behavior from PyPerformance benchmarks, generating traces of ~22 million branches per workload. Implemented seven predictor designs, ranging from a simple Branch Target Buffer to state-of-the-art Indirect Target TAgged GEometric length predictor (ITTAGE), coming up with an experimental hybrid predictor that achieved the lowest misprediction ratio.

Features:

  • Seven predictor architectures including BTB, two-level, cascaded, and ITTAGE with 2-bit counter variations, implemented as described in the linked papers.
  • Hybrid predictor combining ITTAGE's global history with local history tables for improved accuracy.
  • Performance evaluation across eight PyPerformance benchmarks with misprediction ratio analysis.

Big Data for GNP

Evaluating the Usefulness of Big Data to Glacier National Park Management

This project looks at whether big data can realistically help support management decisions at Glacier National Park. Using Zartico, a data intelligence company, as a case study, my team assessed the practicality of using large-scale visitor data to improve park planning and decision-making. By analyzing and visualizing visitor patterns and comparing them with current park records, the project shows where big data adds value and where it falls short, helping inform future decisions about investing in similar tools.

Highlights:

  • Evaluated big data platforms using management-focused criteria: credibility, labor requirements, and relevance.
  • Analyzed visitor movement, origin, and congestion patterns using Zartico's integrated data visualization and analytics software.
  • Identified key limitations, including small sample sizes, limited granularity, and high labor demands.
  • Produced actionable recommendations to help park managers assess big data tools and providers.

Dots and Boxes AI Player

Dots and Boxes AI Player

Developed an AI player for the game "Dots and Boxes" using the Minimax algorithm with alpha-beta pruning and iterative deepening. The system evaluates board states through a heuristic-driven clustering method that prioritizes box completion and strategic placement of the edges. Competed against 30 teams in a class-wide tournament and placed in the top 3.

Features:

  • Evaluation function that clusters adjacent boxes and scores based on edge completion priority (0-3 edges).
  • Reader/writer communication protocol to handle referee interactions and game state synchronization.
  • Complete board state management with illegal move detection and mental model tracking of claimed edges.
